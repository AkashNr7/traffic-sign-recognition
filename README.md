Traffic sign recognition using Pytorch 


Project Overview:
This project implements a trffic sign reconition system using a CNN and Machine learing with help of pythorch.
This model is trained and classified to identify signs into multiple catogories using image data form live camera feed.


Technologies used:
1.python
2.pythorch
3.openCV
4.numpy
5.matplotlib


Dataset :
This project uses the german traffic  sign recongnition benchmark (GTSRB) dataset
Due to Github size limitation the dataset is not included in this repository.
  
How to run:
TRAIN:
python train.py

TEST THE MODEL:
python test.py

RECOGNITION:
python recognition.py

MODEL details:
CNN moodel built using pytorch and openCV.
multi-class classification.
Cross-entropy loss
optimizer:adam
